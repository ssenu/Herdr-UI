# 탭을 끌어 분할하기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 탭을 끌어 작업 화면의 네 가장자리에 놓으면, 지금 탭이 그 방향으로 나뉘고 끌어온 탭이 거기로 옮겨 온다.

**Architecture:** `my-tabs`는 눌린 탭을 기억했다가 포인터가 탭 바를 벗어나면 전체 창 오버레이 `my-tab-drag`를 연다. 오버레이가 구역 판단과 미리보기, 실제 이동을 맡고, 판단은 `mods/my-tab-drag/logic.js`에 둔다. 터미널은 `terminal.park` + `terminal.keep`으로 프로세스를 유지한 채 옮기고, 뷰어는 닫고 분할 칸에 다시 연다.

**Tech Stack:** Herdr mods (JS, `gpui-kit`, `gpui-base`, `herdr`), `node:test`.

## Global Constraints

- 옮기는 탭: 한 칸짜리 터미널·에이전트 탭, 파일을 연 `my-viewer` 탭. 여러 칸 탭, 원격 탭, 지금 보고 있는 탭은 막고 이유를 이름표에 보여 준다.
- 놓는 구역: 작업 화면 네 가장자리에서 안쪽 폭·높이의 25%. 겹치면 가까운 가장자리. 가운데와 작업 화면 밖은 취소.
- `terminal.keep`은 비동기로 끝날 수 있다. 다음 단계는 `panes()`에 결과가 보인 뒤 진행하고, 2초 안에 안 보이면 알린다.
- 앱은 `mod.json`이 없는 새 mod 폴더를 레이아웃에 칸으로 끼워 넣는다. 설치는 반드시 `install.ps1`로 한다(`mod.json`을 먼저 복사한다).
- `cx.notify()`를 render 안에서 부르지 않는다. 사용자에게 보이는 글은 한국어.
- 도구 주의: 코드는 파일 편집 도구로 쓴다(Bash heredoc은 백슬래시를 망가뜨린다). `install.ps1`은 UTF-8 BOM과 Windows PowerShell 5.1 호환을 유지한다.
- 테스트는 Git Bash에서 실행한다: `node --test tests/*.test.mjs`.

```js
// Pure helpers for my-tab-drag. No herdr or gpui imports, so `node --test` can load this file.

const ACTIVE = "지금 보고 있는 탭은 옮길 수 없어요", MANY = "여러 칸으로 나뉜 탭은 옮길 수 없어요", REMOTE = "원격 탭은 옮길 수 없어요", OTHER = "이 탭은 옮길 수 없어요";
const GAP = 8, EDGE = 0.25;

/** What dragging this tab can do. own: the shared my-viewer.own map (token → { tab, path, on }). */
export function tabMove(tabId, { activeTab, panes, machine, own }) {
  if (tabId === activeTab) return { blocked: ACTIVE };
  if (machine) return { blocked: REMOTE };
  const list = panes.filter(p => p.tab === tabId);
  if (list.length > 1) return { blocked: MANY };
  const pane = list[0];
  if (!pane) return { blocked: OTHER };
  if (pane.mod === "my-viewer") {
    const entry = Object.values(own ?? {}).find(v => v.tab === tabId);
    return entry?.path ? { kind: "viewer", path: entry.path, on: entry.on ?? null } : { blocked: OTHER };
  }
  if (pane.mod || !pane.terminal) return { blocked: OTHER };
  if (pane.terminal.includes("/")) return { blocked: REMOTE };
  return { kind: "terminal", terminal: pane.terminal };
}

/** The box tabs show in: below the bar, above the status bar, beside the open panel. Null when it can't be told. */
export function workArea({ bar, window, panelWidth, statusHeight }) {
  if (!bar || !window) return null;
  const x = bar.x + GAP, y = bar.y + bar.height + GAP;
  const right = window.width - GAP - (panelWidth ? panelWidth + GAP : 0), bottom = window.height - statusHeight - GAP;
  return right > x && bottom > y ? { x, y, width: right - x, height: bottom - y } : null;
}

/** Which side a release at position splits. The outer quarter of each side counts; a corner goes to the nearer edge. */
export function dropZone(position, area) {
  if (!position || !area) return null;
  const left = (position.x - area.x) / area.width, up = (position.y - area.y) / area.height;
  if (left < 0 || left > 1 || up < 0 || up > 1) return null;
  const sides = [["left", left], ["right", 1 - left], ["up", up], ["down", 1 - up]];
  const [zone, distance] = sides.reduce((a, b) => (b[1] < a[1] ? b : a));
  return distance < EDGE ? zone : null;
}

/** The half of the area the moved tab takes. */
export function previewBox(zone, { x, y, width, height }) {
  if (zone === "left") return { x, y, width: width / 2, height };
  if (zone === "right") return { x: x + width / 2, y, width: width / 2, height };
  if (zone === "up") return { x, y, width, height: height / 2 };
  return { x, y: y + height / 2, width, height: height / 2 };
}

/** Herdr splits only right and down, so left and up swap afterward. */
export function placement(zone) {
  return { left: { place: "right", swap: "left" }, right: { place: "right", swap: null }, up: { place: "down", swap: "up" }, down: { place: "down", swap: null } }[zone];
}

const NAMES = { left: "왼쪽", right: "오른쪽", up: "위쪽", down: "아래쪽" };

export function dropLabel(zone, move) {
  if (move.blocked) return move.blocked;
  return zone ? `놓으면 ${NAMES[zone]}으로 분할` : "놓으면 취소";
}
```

```js
// Drag layer for tabs: a transparent full-window overlay opened when a tab is dragged off the tab bar.
// It shows the half the tab would take. Releasing near an edge of the work area moves the tab beside
// the focused pane: a terminal keeps running (park, then keep), a viewer reopens there from its draft.
import { View, div } from "gpui-kit";
import { h_flex } from "gpui-base";
import { props, closeOverlay, run, theme, notify, shared, spaces, panes, layout } from "herdr";
import { tabMove, workArea, dropZone, previewBox, placement, dropLabel } from "./logic.js";

const WAIT_MS = 2000, POLL_MS = 100, DRAFT_MS = 300;

function find(node, id) {
  if (node?.id === id) return node;
  for (const child of node?.children ?? []) {
    const found = find(child, id);
    if (found) return found;
  }
  return null;
}

async function until(cx, test) {
  for (let t = 0; t < WAIT_MS; t += POLL_MS) {
    if (test()) return true;
    await cx.sleep(POLL_MS);
  }
  return test();
}

export default class MyTabDrag extends View {
  init(_props, cx) {
    this.pos = null; this.size = null; this.done = false;
    const space = spaces().find(s => s.active), tabId = props()?.tab?.id;
    this.move = tabMove(tabId, { activeTab: space?.tabs.find(t => t.active)?.id, panes: panes(), machine: space?.machine ?? null, own: shared("my-viewer.own") });
    this.handle = cx.focus_handle();
    this.handle.focus();
  }

  area() {
    const root = layout(), panel = find(root, "panel"), status = find(root, "status");
    return workArea({ bar: shared("my-tabs.bounds"), window: this.size, panelWidth: panel && !panel.hidden ? panel.size?.px ?? 0 : 0, statusHeight: status?.size?.px ?? 0 });
  }

  zone() {
    return this.move.blocked ? null : dropZone(this.pos, this.area());
  }

  close() { const id = props()?.overlay; if (id) closeOverlay(id); }

  finish(position, cx) {
    if (this.done) return;
    this.done = true;
    if (position) this.pos = position;
    const zone = position ? this.zone() : null;
    cx.notify(); // hides the label and preview at once
    if (!zone) { this.close(); return; }
    cx.spawn(async cx => {
      try {
        if (this.move.kind === "terminal") await this.moveTerminal(zone, cx);
        else await this.moveViewer(zone, cx);
      } catch (e) {
        notify({ title: "탭을 옮기지 못했어요", body: String(e), level: "error", timeout: 5000 });
      } finally { this.close(); }
    });
  }

  async moveTerminal(zone, cx) {
    const { terminal } = this.move, { place, swap } = placement(zone);
    const shown = () => panes().find(p => p.terminal === terminal);
    run("terminal.park", { terminal });
    if (!await until(cx, () => !shown())) throw new Error("터미널을 탭에서 떼지 못했어요");
    run("terminal.keep", { terminal, place });
    if (!await until(cx, () => Boolean(shown()))) throw new Error("터미널이 새 칸에 나타나지 않았어요");
    if (swap) { run("pane.focus", { terminal }); run("pane.swap", { direction: swap }); }
  }

  async moveViewer(zone, cx) {
    const { path, on } = this.move, { place, swap } = placement(zone), tabId = props().tab.id;
    run("tab.close", { id: tabId, confirmed: true });
    if (!await until(cx, () => !panes().some(p => p.tab === tabId))) throw new Error("뷰어 탭을 닫지 못했어요");
    await cx.sleep(DRAFT_MS); // the closed viewer writes its last draft
    const before = new Set(panes().map(p => p.pane));
    run("pane.split", { direction: place, mod: "my-viewer", props: { path, on, root: null } });
    const fresh = () => panes().find(p => p.mod === "my-viewer" && !before.has(p.pane));
    if (!await until(cx, () => Boolean(fresh()))) throw new Error("새 칸이 나타나지 않았어요");
    if (swap) { run("pane.focus", { pane: fresh().pane }); run("pane.swap", { direction: swap }); }
  }

  render() {
    const t = theme(), { tab } = props() ?? {}, zone = this.done ? null : this.zone(), area = zone ? this.area() : null;
    const box = zone ? previewBox(zone, area) : null;
    return div().id("my-tab-drag").track_focus(this.handle).size_full().bg("#00000001")
      .on_size_change(size => { this.size = size; })
      .on_key_down((e, cx) => { if (e.key === "escape") { cx.stop_propagation(); this.finish(null, cx); } })
      .on_mouse_move((e, cx) => { if (!this.done) { this.pos = e.position; cx.notify(); } })
      .on_mouse_up("left", (e, cx) => this.finish(e.position, cx))
      // Released before this layer opened: the next press just closes it.
      .on_mouse_down("left", (_e, cx) => { cx.stop_propagation(); this.finish(null, cx); })
      .when(Boolean(box), el => el.child(div().absolute().left(box.x).top(box.y).w(box.width).h(box.height)
        .rounded(10).bg(t.accent).opacity(0.18).border_1().border_color(t.accent)))
      .when(Boolean(this.pos) && !this.done, el => el.child(
        h_flex().absolute().left(this.pos.x + 14).top(this.pos.y + 12).h(26).px(10).gap(6).items_center()
          .rounded(7).bg(t.popover).border_1().border_color(this.move.blocked ? t.blocked : t.accent).text_color(t.foreground).text_size(12)
          .child(tab?.name ?? "")
          .child(div().text_color(t.dim).child(`· ${dropLabel(zone, this.move)}`))));
  }
}
```

```markdown
- 탭을 누른 채 탭 바 밖으로 끌어 작업 화면 **네 가장자리** 중 하나에 놓으면, 지금 탭이 그 방향으로 나뉘고 끌어온 탭이 거기로 옮겨 옵니다. 가장자리에서 안쪽 25%까지가 놓는 구역이고, 나뉠 자리가 미리 표시됩니다. 가운데나 화면 밖에 놓거나 Esc를 누르면 취소됩니다.
- 터미널과 에이전트는 실행 중인 프로세스가 그대로 옮겨 옵니다. 파일 뷰어는 닫았다가 새 칸에 다시 열리고, 저장 안 한 내용은 초안에서 복원됩니다.
- 탭 바 안에서 끌면 지금처럼 순서만 바뀝니다.

```

설치 절의 `열한 mod`를 `열두 mod`로, 수동 설치의 `열한 폴더`를 `열두 폴더`로 바꾼다. 제거 절의 mod 목록에 `my-tab-drag`를 `my-tabs` 앞에 더한다. 알려진 한계 끝에 추가:

```markdown
- 탭 끌어 분할하기는 한 칸짜리 터미널·에이전트 탭과 파일을 연 뷰어 탭만 옮깁니다. 지금 보고 있는 탭과 원격 탭은 옮기지 않습니다. 이미 나뉜 화면에서는 포커스된 칸이 나뉩니다. 분할 칸의 뷰어는 탭 이름에 `●` 가 없고, 같은 파일을 다시 드롭하면 새 탭이 열립니다. 분할을 다시 탭으로 빼는 기능은 없습니다.
```
