# Files 패널 파일 이름 검색 — 설계

- 날짜: 2026-11-04
- 대상: `mods/my-files/main.js`, `mods/my-files/logic.js`, `tests/my-files-logic.test.mjs`, `README.md`
- 범위: **파일 이름(경로) 퍼지 검색만**. 내용 검색은 하지 않는다.

## 화면

- 트리 화면(파일을 열지 않은 상태)에서 헤더 바로 아래에 입력칸 한 줄: 플레이스홀더 `이 폴더에서 파일 찾기`.
  - `InputState.new({ placeholder })`는 `init`에서 한 번 만든다. `on("change")`로 검색어 갱신.
- 검색어가 비어 있으면 지금 트리 그대로. 비어 있지 않으면 트리 자리에 **결과 목록**.
- 결과 행: 파일 아이콘 · 파일 이름(맞은 글자 강조: `t.accent`) · 흐린 상위 경로(`mods/my-files`) · 저장 안 한 `●` · git 표시 · `⋯`(로컬만). 높이·간격은 트리 행과 같게.
  - 클릭: 그 파일을 연다(`show(path)`; `.md`는 보기 모드). 검색어는 유지 → `←`로 돌아오면 같은 결과.
  - 드래그: 트리 행과 같은 절대경로 입력(`my-files-drag`).
  - `⋯`: 트리 행과 같은 `my-files-open` 팝업.
- 선택 행(↑/↓로 이동, 처음엔 맨 위)은 `t.selected` 배경.
- 키: ↑/↓ 선택 이동, Enter 선택 행 열기, Esc 검색어 지우기(트리로).
- 최대 200개 표시. 더 있으면 마지막에 `더 있어요 · 검색어를 더 입력하세요`.
- 0개면 `‘<검색어>’와 맞는 파일이 없어요`.

## 목록 (인덱스)

- 검색어를 처음 입력할 때, 현재 Files 루트(`this.root`, 원격이면 `this.on`)의 하위 파일 경로를 명령 한 번으로 받아 메모리에 둔다(루트 기준 상대경로, `/` 구분).
- **모든 파일**(`.gitignore` 무시 안 함). **`.git` 폴더만 제외.** 심볼릭 링크/정션 폴더는 따라가지 않는다(순환 방지).
- 상한 **50,000개**. 넘으면 멈추고 결과 위에 `파일이 너무 많아 처음 50,000개에서만 찾아요`.
- 로컬 Windows: PowerShell에서 .NET `Directory.EnumerateFiles/EnumerateDirectories`로 스택 순회(접근 거부 폴더는 건너뜀). 루트는 작은따옴표 리터럴(`'`과 둥근 작은따옴표는 두 번)로만 넣는다. 출력 UTF-8.
- 원격·유닉스: `sh -c` 스크립트에 루트를 인자로: `cd "$1" && find . -name .git -prune -o -type f -print | head -n 50001`.
- 출력 해석은 `logic.js`(`indexLines`): 줄 단위, `./` 접두와 `\` 구분자 정리, 빈 줄 무시, 50,000 초과면 `truncated`.
- 만드는 동안 입력칸 오른쪽에 `목록 만드는 중…`. 끝나면 결과가 바로 갱신.
- 루트(컨텍스트 키)마다 인덱스를 기억한다. 폴더 감시(`watch`)로 `refresh`가 돌면 그 인덱스를 **오래됨**으로 표시 → 다음 검색어 입력 때 백그라운드로 다시 만들고, 그동안은 예전 인덱스로 거른다.
- 실패(권한, 원격 연결)하면 입력칸 아래 오류 줄(`파일 목록을 만들지 못했어요: …`), 트리는 영향 없음.

## 퍼지 매칭 (`logic.js`, 순수 함수)

- `fuzzyMatch(query, path)` → `{ score, hits: number[] } | null`
  - 대소문자 무시. 검색어를 공백으로 나눈 **모든 조각**이 경로에 맞아야 한다.
  - 각 조각: 글자가 경로에 **순서대로** 나오면 맞음. 파일 이름 부분(마지막 `/` 뒤)에서 먼저 찾아보고, 안 되면 전체 경로에서.
  - 점수(클수록 위): 파일 이름 안에서 맞음 가산, 연속으로 맞은 글자 가산, 단어 시작(경로 맨 앞, `/ . - _` 뒤, 소문자→대문자 경계) 가산, 경로 길이만큼 약간 감점.
  - `hits`: 맞은 글자의 경로 내 위치(강조용, 오름차순, 중복 없음).
- `searchPaths(paths, query, limit)` → `{ results: { path, score, hits }[], more: boolean }` — 점수 내림차순, 같으면 경로 짧은 순 → 사전순. `limit` 초과분은 `more`.
- `splitPath(path)` → `{ dir, name }` (행 표시용).

## 오류·경계

- 루트가 없거나(폴더 없음) 원격 연결 불가 → 입력칸은 보이되 오류 줄.
- 검색 중 루트가 바뀌면(다른 칸 포커스) 진행 중 인덱스 결과는 버리고, 새 루트로 다시.
- 바탕화면 칩으로 루트가 바뀌어도 같은 규칙.

## 테스트

`tests/my-files-logic.test.mjs`에 추가:
- `fuzzyMatch`: 순서대로 맞음/안 맞음, 대소문자, 공백 조각, 파일 이름 우선, 연속·단어 시작 가산, hits 위치.
- `searchPaths`: 정렬, limit/more.
- `indexLines`: `./` 정리, `\` 정리, 빈 줄, 50,000 초과 → truncated.
- 목록 명령: 실제 PowerShell(Windows)·sh로 특수문자(`&`, `'`, `’`, 한글, 공백) 폴더를 순회 — `.git` 하위 제외, 중첩 파일 포함 확인.
