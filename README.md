# Herdr-UI

[Herdr](https://github.com/herdrdev/herdr) 데스크톱 앱을 더 편하게 쓰기 위한 mod 모음입니다.

## 기능 한눈에

- **Files 패널**: 파일을 바로 고치고 저장, `.md` 보기 모드, 이름으로 파일 찾기, 끌어서 경로 넣기, `⋯` 메뉴로 외부 프로그램 열기
- **파일 뷰어 탭**: 터미널처럼 탭으로 여는 파일 보기·편집기. 저장 안 한 내용은 초안으로 보관
- **GitHub 패널**: 지금 저장소의 이슈·PR 목록과 본문, 에이전트에게 작업 넘기기, 이슈 닫기·PR 머지
- **Plugins 패널**: Claude Code·Codex가 지금 폴더에서 보는 MCP 서버와 스킬 목록
- **Sessions 패널**: 지금 저장소의 Claude Code 세션 목록. 누르면 새 탭에서 다시 열기, 열려 있는 세션은 초록 점
- **탭 바**: 패널 버튼(GitHub · Plugin · Session), `+` 메뉴의 파일 뷰어, 스페이스별로 기억하는 패널
- **탭을 끌어 분할하기**: 탭을 화면 가장자리에 놓으면 분할, 옮긴 칸은 탭 바에 칩으로 남음
- **하단 바**: 이 PC의 CPU·RAM·GPU와 ccusage 사용량(오늘 · 5시간 구간 · 남은 시간), 마우스를 올리면 작은 대시보드

전부 설치해도 되고, [원하는 기능만 설치](#원하는-기능만-설치하기)할 수도 있습니다.

| mod | 하는 일 |
|---|---|
| `my-files` | 기본 Files 패널의 복제본. 파일 편집·저장, `.md` 보기 모드, 이름으로 파일 찾기, 드래그로 경로 넣기 |
| `my-files-drag` | 드래그하는 동안 창 전체를 덮는 투명 레이어 (이름표 표시, 놓으면 붙여넣기) |
| `my-files-open` | 파일 행의 `⋯` 메뉴: 기본 프로그램 / VS Code / 탐색기에서 보기 / 경로 복사 |
| `my-github` | 현재 저장소의 GitHub 이슈·PR 패널 (gh CLI 사용) |
| `my-plugins` | 지금 폴더에서 Claude Code·Codex가 보는 MCP 서버와 스킬 목록 (읽기 전용) |
| `my-sessions` | 지금 저장소의 Claude Code 세션 목록. 누르면 새 탭에서 다시 열기 |
| `my-new-menu` | 기본 `+` 메뉴의 복제본. "파일 뷰어" 항목 추가 |
| `my-viewer` | 터미널처럼 탭으로 열리는 파일 뷰어·편집기 |
| `my-status` | 기본 하단 바의 복제본. 이 PC의 CPU·RAM·GPU와 ccusage 사용량 표시 |
| `my-status-dash` | 하단 바 수치에 마우스를 올리면 뜨는 최근 5분 그래프 |
| `my-usage-dash` | 하단 바 사용량에 마우스를 올리면 뜨는 사용량 대시보드 |
| `my-tab-drag` | 탭을 끌어 작업 화면의 가장자리에 놓으면 분할 |
| `my-tabs` | 기본 탭 바의 복제본. Files · Changes 옆에 GitHub · Plugin · Session 버튼 추가 |

## 기능

### Files 패널 (`my-files`)

- **편집과 저장**: 로컬 텍스트 파일을 패널에서 바로 고치고 **Ctrl+S**로 저장합니다.
  - 저장하지 않은 파일은 목록과 헤더에 **●** 가 붙습니다. 다른 파일이나 스페이스로 갔다 와도 고친 내용이 남아 있습니다(앱을 끄면 사라짐).
  - 다른 곳(에이전트, git 등)에서 파일이 바뀌면, 고치지 않은 파일은 화면이 자동으로 새로고침되고, 고친 파일은 **"디스크의 파일이 바뀌었어요"** 표시줄이 뜹니다. [내 것으로 덮어쓰기] / [디스크 버전 불러오기] 중 고릅니다.
  - CRLF 줄바꿈 파일은 CRLF로 저장됩니다.
- **읽기 전용 + nano**: 원격 스페이스(ssh 머신)의 파일과 400,000자가 넘는 파일은 읽기 전용입니다. **[nano로 열기]** 를 누르면 오른쪽에 칸을 나눠 nano로 엽니다.
- **`.md` 보기 모드**: `.md` / `.markdown` 파일은 렌더링된 화면으로 먼저 열립니다. 오른쪽 위 **[보기] [편집]** 으로 오갑니다. 편집 중인 내용(저장 전)도 보기에 반영됩니다.
- **외부 프로그램으로 열기**: 각 행 오른쪽의 **`⋯`** 를 누르면 [기본 프로그램으로 열기] [VS Code로 열기] [탐색기에서 보기] [경로 복사] 메뉴가 뜹니다. 폴더도 됩니다. 원격 스페이스에서는 보이지 않습니다.
- **[바탕화면]**: 헤더의 칩을 누르면 포커스된 칸 대신 바탕화면 폴더를 보여 줍니다. 다시 누르면 원래대로.
- **파일 찾기**: 목록 위 입력칸에 이름 일부를 치면 지금 폴더 아래 **모든 파일**(`.git` 제외)에서 퍼지 검색합니다(`mainjs` → `mods/my-files/main.js`). 공백으로 나누면 조각이 모두 맞아야 합니다. ↑/↓ 선택, Enter 열기, Esc 지우기. 결과 행도 클릭·드래그·`⋯` 가 트리와 같습니다. 처음 입력할 때 목록을 만들고, 폴더 안의 파일이 바뀌면 다음 입력 때 다시 만듭니다(원격은 1분이 지난 뒤의 입력 때).
- **드래그로 경로 넣기**: 파일·폴더를 누른 채 패널 밖으로 끌어 터미널 위에서 놓으면, 마지막으로 선택한 터미널의 프롬프트에 **절대경로**가 입력됩니다(Enter는 누르지 않음). 공백 등이 있으면 `"따옴표"`로 감쌉니다. 패널 위로 돌아와 놓으면 취소.

### 파일 뷰어 (`my-viewer`)

- **탭으로 열기**: 탭 바의 **`+` → 파일 뷰어**를 누르면 지금 폴더에서 파일을 찾는 탭이 열립니다. 고르면 그 탭에 파일이 열립니다.
- **탭 바에 드롭**: Files 패널에서 파일을 끌어 **탭 바** 위에 놓으면 새 탭으로 열립니다. 이름표에 `놓으면 새 탭으로 열기` 가 보입니다. 그 밖의 곳에 놓으면 지금처럼 터미널에 경로가 입력됩니다. 폴더는 탭 바에 놓아도 열리지 않습니다.
- 탭 하나에 파일 하나만 엽니다. 이미 열린 파일을 다시 열면 그 탭으로 이동합니다.
- **편집**: 코드와 텍스트를 고치고 **Ctrl+S**로 저장합니다. `.md` 는 **[보기] [편집]** 을 오갑니다. 400,000자가 넘는 파일과 원격 파일은 읽기 전용입니다. 원격 파일에는 **[nano로 열기]**, 이 PC의 큰 파일에는 **[외부 프로그램으로 열기]** 가 있습니다.
- **표시할 수 없는 파일**(이미지, PDF, 압축 파일 등)은 **[외부 프로그램으로 열기]** 를 보여 줍니다.
- **초안**: 저장하지 않은 내용은 1초쯤 뒤 초안으로 보관됩니다(`<앱 폴더>\data\my-viewer\drafts`). 탭을 닫거나 앱을 꺼도 남아 있고(앱을 강제로 끄거나 앱이 죽으면 마지막 1초쯤 입력한 내용은 잃을 수 있습니다), 그 파일을 다시 열면 `●` 와 함께 복원됩니다. 그사이 원본이 바뀌었으면 **[초안 유지] [디스크 버전 불러오기]** 중 고릅니다.

### 탭을 끌어 분할하기 (`my-tab-drag`)

- 탭을 누른 채 탭 바 밖으로 끌어 작업 화면 **네 가장자리** 중 하나에 놓으면, 지금 탭이 그 방향으로 나뉘고 끌어온 탭이 거기로 옮겨 옵니다. 가장자리에서 안쪽 25%까지가 놓는 구역이고, 나뉠 자리가 미리 표시됩니다. 가운데나 작업 화면 밖에 놓거나 Esc를 누르면 취소되고, 창 밖에서 놓으면 다음 클릭에 닫힙니다.
- 터미널과 에이전트는 실행 중인 프로세스가 그대로 옮겨 옵니다. 파일 뷰어는 닫았다가 새 칸에 다시 열리고, 저장 안 한 내용은 초안에서 복원됩니다.
- 탭 바 안에서 끌면 지금처럼 순서만 바뀝니다.
- 옮긴 칸은 탭 바에 **칩**으로 남습니다. 칩은 그 칸이 있는 탭 바로 뒤에 놓입니다. 누르면 그 칸으로 가고, 포커스된 칩의 버튼으로 **다시 독립 탭으로 빼거나** 닫을 수 있습니다. 터미널과 에이전트는 빼도 프로세스가 그대로입니다. 닫을 때는 일반 탭을 닫을 때와 같은 경로를 거칩니다.

### GitHub 패널 (`my-github`)

- 탭 바의 **GitHub** 버튼으로 엽니다. 포커스된 칸의 폴더가 속한 저장소를 보여 줍니다.
- **[이슈] [PR]** 탭과 **[전체] [내 것] [닫힘]** 필터. 최근 업데이트순 30개.
  - PR에는 초안 여부, 리뷰 상태(승인 / 변경 요청 / 리뷰 대기), CI 결과(✓ / ✗ / ●)가 표시됩니다.
- 항목을 누르면 본문과 코멘트를 마크다운으로 보여 주고, **[브라우저로 열기]** 가 있습니다.
- 상세 화면에서 열린 이슈는 **[이슈 닫기]**, 열린 PR은 **[머지]** 후 **Merge / Squash / Rebase** 를 골라 확인하면 실행됩니다. 브랜치는 지우지 않고, 저장소 규칙(필수 리뷰·체크 등)을 우회하지 않습니다. 실패하면 gh가 알려 준 이유와 **[다시 시도]** 가 나옵니다. 초안 PR에는 버튼이 없습니다.
- **에이전트에게 넘기기**
  - 포커스된 칸이 에이전트(Claude Code 등)면 **[→ Claude Code 입력창에 넣기]**: 작업 문구를 입력창에 넣습니다(Enter는 직접).
  - 아니면 **[새 탭에서 Claude 시작]**: `#번호 제목` 탭을 만들고 Claude가 그 문구로 바로 시작합니다.
  - 문구 예: ``GitHub 이슈 #12 "로그인 버그" 를 해결해줘. <url>`` + ``내용과 코멘트는 `gh issue view 12 --comments` 로 확인해.``
- **목록에서 드래그**: 행을 끌어 터미널 위에 놓으면 `이슈 #78 "제목" https://github.com/… ` 한 줄이 입력됩니다.
- 패널이 보일 때만 2분마다 새로고침합니다. 헤더의 ⟳ 로 바로 새로고침.

### Plugins 패널 (`my-plugins`)

- 탭 바의 **Plugin** 버튼으로 엽니다. 포커스된 칸의 폴더에서 에이전트가 쓰는 **MCP 서버**와 **스킬**을 보여 줍니다. 읽기만 하고 아무것도 바꾸지 않습니다.
- 헤더의 **[Claude] [Codex]**: 포커스된 칸이 Codex면 Codex, 아니면 Claude가 자동으로 골라집니다. 직접 눌러 바꿀 수 있습니다(다른 칸으로 가면 다시 자동).
- **[MCP] [Skills]** 탭. 출처별로 묶어 보여 줍니다.

  | | MCP | Skills |
  |---|---|---|
  | Claude | `~/.claude.json`(전역, 이 폴더의 로컬), 저장소의 `.mcp.json`(프로젝트) | `~/.claude/skills`(전역), 저장소의 `.claude/skills`(프로젝트), 설치된 플러그인의 `skills/`(플러그인:이름) |
  | Codex | `~/.codex/config.toml`(전역), 저장소의 `.codex/config.toml`(프로젝트) | `~/.agents/skills`(전역), 지금 폴더부터 저장소 루트까지의 `.agents/skills`(프로젝트) |

- MCP 행에는 실행 명령이나 URL이, 스킬 행에는 설명이 보입니다. Codex에서 `enabled = false` 인 서버는 `꺼짐`.
- 행을 누르면 상세: 스킬은 SKILL.md 본문(마크다운), MCP는 설정. **env·헤더·토큰 같은 비밀 값은 `••••` 로 가립니다.**
- **드래그**: 스킬 행을 터미널에 놓으면 Claude는 `/이름 `(플러그인은 `/플러그인:이름 `), Codex는 `$이름 ` 이 입력됩니다. MCP 행은 `이름 MCP `.
- 각 행의 **`⋯`**: SKILL.md 또는 설정 파일을 기본 프로그램 / VS Code / 탐색기로 엽니다(로컬만).
- 원격 스페이스에서는 그 머신의 설정을 읽습니다.
- 패널이 보일 때와 폴더·에이전트가 바뀔 때 다시 읽습니다. ⟳ 로 바로 새로고침.

### Sessions 패널 (`my-sessions`)

- 탭 바의 **Session** 버튼으로 엽니다. 포커스된 칸의 저장소에서 시작한 Claude Code 세션을 최근 순으로 보여 줍니다(최대 100개).
- **[전체]**: 저장소 루트와 하위 폴더, git worktree에서 시작한 세션. **[지금 폴더]**: 포커스된 칸의 폴더에서 시작한 세션만. 칩을 누르면 다시 읽지 않고 바로 바뀝니다.
- 행에는 세션 제목(직접 붙인 이름 → 자동 제목)과 `3시간 전 · main · mods/x`(시간 · 브랜치 · 폴더)가 보입니다. 저장소 루트에서 시작한 세션은 폴더를 적지 않습니다.
- 이미 열려 있는 세션은 제목 앞에 **초록 점**이 붙습니다. 이 머신의 어디서 열었든(Herdr 밖 포함) 표시됩니다. 눌러도 지금 탭으로 이동하지 않고 새 탭으로 열리니, 같은 세션을 두 곳에서 쓰지 않도록 조심하세요.
- 행을 누르면 **새 탭**이 세션 제목 이름으로 열리고, 그 세션의 시작 폴더에서 `claude -r <ID>` 가 실행됩니다. 더블클릭해도 탭은 하나만 열립니다.
- 세션 파일의 앞뒤 일부만 읽어 제목·폴더·브랜치만 가져옵니다. 대화 내용은 읽어 오지 않습니다. 사용자 메시지가 없는 빈 세션은 목록에서 뺍니다.
- 원격 스페이스에서는 그 머신의 세션을 읽습니다. 패널이 보이는 동안 30초마다 다시 읽고, ⟳ 로 바로 새로고침합니다. 같은 저장소 안에서 칸을 옮기면 목록을 유지한 채 다시 읽습니다.

### 시스템 모니터 (`my-status`)

- 하단 바 오른쪽에 **이 PC**의 `CPU 13%  RAM 19.7/31.4GB  GPU 8%` 를 5초마다 갱신해 보여 줍니다. 사용률 90% 이상이면 강조색으로 바뀝니다. Windows에서만 표시합니다.
- 원격 스페이스에서도 이 PC의 값이며, 앞에 `이 PC` 가 붙습니다.
- 수치에 마우스를 올리면 CPU·RAM·GPU의 현재 값과 **최근 5분 막대그래프**가 뜹니다. 그래프는 앱을 켠 뒤부터 쌓입니다.

### 사용량 요약 (`my-status`)

- 하단 바의 시스템 수치 왼쪽에 `Today $104 · 5h $33 · 2h15m left` 를 보여 줍니다. `5h` 는 Claude Code 사용 기록을 5시간 단위로 묶은 지금 구간에서 쓴 금액이고, `left` 는 그 구간이 끝날 때까지 남은 시간입니다. 지금 구간이 없으면 오늘 비용만 나옵니다. Windows에서만 표시합니다.
- [ccusage](https://github.com/ryoppippi/ccusage)를 앱을 켤 때와 그 뒤 5분마다 실행해 읽습니다. Node.js(`npx`)가 필요합니다.
- 마우스를 올리면 현재 블록의 진행 막대와 예상 비용, 최근 7일 막대그래프, 오늘 모델별 비용, 이번 달 합계가 뜹니다.
- 금액은 API 가격으로 계산한 **추정치**이며 구독 요금과 다릅니다. 일별 값은 ccusage가 찾은 모든 CLI의 합이고, 블록은 Claude Code만 있습니다. 원격 스페이스에서도 **이 PC**의 기록입니다.
- `ccusage@latest`로 실행하므로 실행할 때마다 npm을 확인하고 새 버전이 자동으로 실행됩니다. 출력 형식이 바뀌면 마지막 값이 그대로 남거나, 앱을 새로 켠 뒤에는 표시가 사라질 수 있습니다.

## 요구 사항

- Herdr 앱 (0.1.13에서 확인). 설치 스크립트는 Windows(PowerShell)용입니다. 다른 OS는 [수동 설치](#수동-설치)를 보세요.
- GitHub 패널: [GitHub CLI](https://cli.github.com) `gh` 가 설치되고 로그인돼 있어야 합니다(`gh auth login`). 원격 스페이스에서 쓰려면 그 머신에도 gh가 있어야 합니다.
- Sessions 패널: 세션을 여는 머신에 Claude Code의 `claude` 명령이 있어야 합니다.
- [nano로 열기]: 그 머신에 `nano`가 있어야 합니다. Windows에서는 Git for Windows에 들어 있습니다.
- [VS Code로 열기]: `code` 명령이 PATH에 있어야 합니다(VS Code 설치 시 기본값).
- 하단 바 사용량: Node.js(`npx`)가 있어야 합니다.

## 설치 (Windows)

Herdr를 한 번 실행한 뒤:

```powershell
git clone https://github.com/ssenu/Herdr-UI.git
cd Herdr-UI
.\install.cmd            # 또는: powershell -ExecutionPolicy Bypass -File .\install.ps1
```

설치 스크립트가 하는 일:

1. `mods\` 의 열세 mod를 `~\.config\herdr-app\mods\` 에 복사합니다.
2. 레이아웃 `my-layout` 을 고칩니다. 없으면 기본 레이아웃 `main` 을 `my-layout` 으로 복제한 뒤 고칩니다.
   - Files 칸: `files` → `my-files`
   - 탭 바: `tabs` → `my-tabs`
   - 하단 바: `workspace-status` → `my-status`
   - 오른쪽 패널(`panel-body`)에 `github` 칸(`my-github`) 추가
   - 오른쪽 패널(`panel-body`)에 `plugins` 칸(`my-plugins`) 추가
   - 오른쪽 패널(`panel-body`)에 `sessions` 칸(`my-sessions`) 추가
   - 고치기 전 파일은 `my-layout.json.bak-<시각>` 으로 백업합니다.
3. 지금 레이아웃이 `my-layout` 이 아니면 그 레이아웃으로 바꿉니다.

옵션:

```powershell
.\install.cmd -Layout work      # 내 다른 레이아웃(layouts\work.json)에 연결
.\install.cmd -ModsOnly         # mod만 복사하고 레이아웃은 건드리지 않음
```

`-ModsOnly` 는 mod 파일만 갱신합니다. (새 패널 칸은 추가되지 않고 하단 바도 `my-status`로 바뀌지 않으므로, 새 버튼이 생긴 업데이트에서는 옵션 없이 실행하세요.)

Herdr 기본 레이아웃(`main`, `terminals`, `win98`)은 직접 고칠 수 없어서 대상으로 줄 수 없습니다.
mod와 레이아웃은 저장하면 바로 적용되므로 앱을 다시 켤 필요가 없습니다.

## 원하는 기능만 설치하기

`install.cmd` 는 전부 설치합니다. 일부만 쓰려면 아래 묶음 중 원하는 것만 [수동 설치](#수동-설치)처럼 넣으세요. mod끼리 서로 부르는 곳이 있어 묶음 단위로 넣어야 동작합니다.

| 묶음 | 복사할 `mods/` 폴더 | 레이아웃에서 바꿀 곳 |
|---|---|---|
| **하단 바** (시스템 모니터 + 사용량) | `my-status`, `my-status-dash`, `my-usage-dash` | `"mod": "workspace-status"` → `"my-status"` |
| **Files 패널** (+ 탭 바에 드롭해 여는 파일 뷰어) | `my-files`, `my-files-drag`, `my-files-open`, `my-viewer` | `"mod": "files"` → `"my-files"` |
| **탭 바와 패널** (GitHub · Plugins · Sessions, `+` 파일 뷰어, 탭 끌어 분할) | `my-tabs`, `my-new-menu`, `my-tab-drag`, `my-github`, `my-plugins`, `my-sessions`, `my-viewer`, `my-files`, `my-files-drag`, `my-files-open` | `"mod": "tabs"` → `"my-tabs"`, `panel-body` 에 github · plugins · sessions 칸 추가 |

- **하단 바**는 다른 묶음 없이 혼자 동작합니다.
- **Files 패널**만 넣으면 기본 탭 바를 그대로 쓰므로 패널 버튼과 `+` 메뉴의 파일 뷰어는 없습니다. 파일을 탭 바(창 맨 위)에 끌어 놓으면 뷰어 탭이 열립니다.
- **탭 바와 패널**이 한 묶음인 이유:
  - GitHub · Plugin · Session 버튼은 `my-tabs` 에 있고, 버튼은 세 패널이 있다고 보고 항상 보입니다.
  - `+` 메뉴(`my-new-menu`)와 탭 끌기(`my-tab-drag`)도 `my-tabs` 가 엽니다.
  - 뷰어와 `+` 메뉴는 `my-files` 의 아이콘을, 패널의 `⋯` 메뉴와 끌기는 `my-files-open` · `my-files-drag` 를 씁니다. 그래서 `my-files` 폴더는 복사하되, 레이아웃의 Files 칸은 기본 `files` 로 둬도 됩니다.
- 폴더를 손으로 복사할 때는 **Herdr를 끄고** 복사하거나, 각 폴더의 `mod.json` 을 먼저 넣으세요. 앱이 켜진 상태에서 `mod.json` 없는 새 mod 폴더가 생기면, 앱이 그것을 레이아웃에 칸으로 끼워 넣습니다.
- 넣은 뒤 `herdr-app status` 의 `errors` 가 비어 있는지 확인하세요.

## 수동 설치

1. `mods/` 안의 열세 폴더를 `~/.config/herdr-app/mods/` 에 복사합니다.
2. 쓰는 레이아웃(`~/.config/herdr-app/layouts/<이름>.json`, 기본 레이아웃이면 먼저 `herdr-app do layout.clone --name main --as my-layout`)에서:
   - `"mod": "files"` → `"mod": "my-files"`
   - `"mod": "tabs"` → `"mod": "my-tabs"`
   - `"mod": "workspace-status"` → `"mod": "my-status"`
   - `"id": "panel-body"` 의 `children` 끝에 추가:
     ```json
     { "id": "github", "type": "block", "content": { "mod": "my-github" } },
     { "id": "plugins", "type": "block", "content": { "mod": "my-plugins" } },
     { "id": "sessions", "type": "block", "content": { "mod": "my-sessions" } }
     ```
3. `herdr-app status` 의 `errors` 가 비어 있으면 됩니다.

```powershell
git pull
.\install.cmd
```

mod는 덮어씁니다. 레이아웃은 백업한 뒤 빠진 칸만 추가하므로 다시 실행해도 안전합니다.

## 제거

1. 백업(`layouts\my-layout.json.bak-<시각>`)을 `my-layout.json` 으로 되돌리거나, 위 여섯 가지를 원래대로(`files`, `tabs`, `workspace-status`, github·plugins·sessions 칸 삭제) 고칩니다.
2. `~\.config\herdr-app\mods\` 에서 `my-files`, `my-files-drag`, `my-files-open`, `my-github`, `my-new-menu`, `my-plugins`, `my-sessions`, `my-status`, `my-status-dash`, `my-tab-drag`, `my-tabs`, `my-usage-dash`, `my-viewer` 폴더를 지웁니다.
3. 뷰어 초안까지 지우려면 `~\.config\herdr-app\data\my-viewer\` 를 지웁니다.

## 알려진 한계

- 드래그로 넣는 경로·문구는 놓은 칸이 아니라 **마지막으로 선택한 터미널**에 들어갑니다(mod가 칸의 화면 위치를 알 수 없음). 그리고 **클립보드 내용이 바뀝니다**.
- 원격 파일은 패널에서 편집할 수 없습니다(nano로 엽니다). 저장하지 않은 편집 내용은 앱을 끄면 사라집니다.
- 파일 찾기는 폴더당 처음 50,000개 파일에서만 찾고, 결과는 200개까지 보여 줍니다. 링크·정션 폴더 안은 찾지 않습니다.
- `.md` 보기에서 상대경로 이미지·링크는 동작하지 않습니다.
- `my-files`, `my-tabs`, `my-status`, `my-new-menu` 는 기본 mod의 복제본이라 Herdr가 기본 `files`/`tabs`/`workspace-status`/`new-menu` 를 업데이트해도 자동으로 따라가지 않습니다.
- 탭 바를 `my-tabs` 로 바꾸면 스페이스별로 기억하던 패널 선택이 한 번 초기화됩니다.
- Plugins 패널은 읽기 전용입니다(켜기/끄기·삭제는 각 에이전트에서: Claude는 `/mcp`, `claude mcp remove`). Codex 시스템 스킬과 `/etc/codex/skills` 는 보이지 않습니다. 설정을 바꾼 뒤 열린 세션에 반영되는지는 에이전트에 달려 있습니다.
- Plugins 패널은 Claude 플러그인이 제공하는 MCP 서버와 꺼 둔 플러그인/서버 상태(`enabledPlugins`, `disabledMcpServers`)를 반영하지 않습니다. Codex의 `CODEX_HOME`은 무시하고 `~/.codex`를 읽으며, 원격 스페이스는 유닉스(sh) 머신으로 가정합니다.
- Sessions 패널의 초록 점은 목록을 다시 읽을 때 바뀌므로 최대 30초 늦을 수 있습니다(⟳ 로 바로 반영). Claude Code의 내부 파일 형식에 기대므로, 형식이 바뀌면 제목이나 초록 점이 안 보일 수 있습니다. Codex 세션은 보이지 않습니다. 탭이 열리는 머신에 `claude` 명령이 있어야 하고, 원격 스페이스는 유닉스(sh) 머신으로 가정합니다. 후보 폴더(저장소 이름으로 시작하는 폴더 포함)에서 최근 파일 300개만 읽으므로, 이름이 비슷한 폴더의 세션이 아주 많으면 일부가 안 보일 수 있습니다. 드라이브 루트나 `/` 를 저장소로 쓰면 하위 폴더의 세션은 보이지 않습니다. 실제 원격 머신과 macOS, 시작 폴더가 지워진 세션을 여는 경우는 아직 확인하지 않았습니다.
- 파일 뷰어는 이미지·PDF를 탭에서 보여 주지 않습니다(외부 프로그램으로 엽니다). 탭을 닫을 때 묻지 않는 대신 초안을 복원합니다. 초안은 그 PC에만 남습니다. 1 MiB가 넘는 파일은 읽지 못합니다. 탭 바에 드롭하기 전까지 마우스가 탭 바 위를 한 번도 지나지 않았으면 창 맨 위 40px을 탭 바로 칩니다.
- 탭 끌어 분할하기는 한 칸짜리 터미널·에이전트 탭과 파일을 연 뷰어 탭만 옮깁니다. 지금 보고 있는 탭과 원격 탭, 하위 에이전트가 있는 에이전트 탭은 옮기지 않습니다. 같은 파일을 두 뷰어로 열면 각자 수정 내용을 따로 가지고 초안은 하나를 같이 쓰므로, 마지막에 쓴 쪽이 남습니다. 뷰어를 옮기면 실행 취소 기록과 스크롤 위치는 처음으로 돌아갑니다. 이미 나뉜 화면에서는 포커스된 칸이 나뉩니다. 분할 칸의 뷰어는 탭 이름에 `●` 가 없고, 같은 파일을 다시 드롭하면 새 탭이 열립니다. 같은 터미널을 탭과 분할 칸에 동시에 띄울 수는 없어서, 탭 대신 칩이 남습니다. 칩은 끌 수 없고 우클릭 메뉴가 없으며, 탭으로 빼면 탭 바 끝에 생깁니다. 탭의 `×` 는 칩의 칸까지 탭 전체를 닫습니다. 왼쪽과 위쪽은 이웃한 칸과 자리를 바꾸는 방식이라, 이미 나뉜 화면에서는 그 칸의 배치에 따라 결과가 달라질 수 있습니다. 레이아웃의 터미널 블록에 포커스가 있으면 "분할할 칸을 먼저 눌러 주세요"라는 안내가 뜨고 탭은 그대로 남습니다.
- 시스템 모니터는 Windows에서만, 항상 이 PC의 값을 보여 줍니다. 5초마다 PowerShell을 한 번 실행합니다. 그래프는 메모리에만 있어 앱을 끄면 사라집니다. GPU 값은 작업 관리자와 조금 다를 수 있습니다.

## 개발

```powershell
npm test                                              # logic.js 단위 테스트 (Node 22+)
herdr-app check $env:USERPROFILE\.config\herdr-app\mods\my-files   # 설치된 mod 로드 확인
```

- `npm test` 는 `sh` 를 찾지 못하면 sh 실행 테스트를 건너뜁니다. Windows에서 전부 돌리려면 Git Bash에서 `node --test tests/*.test.mjs` 를 실행하세요.
- 화면·herdr 호출은 각 mod의 `main.js`, 테스트 가능한 판단 로직은 `logic.js` 에 있습니다.
- mod는 자기 폴더 밖의 파일을 import할 수 없어서, 여러 mod가 쓰는 파일(`where.js`, `viewer-open.js`, `my-viewer/files-logic.js`)은 복사본을 둡니다. 원본을 고치면 복사본도 같이 고쳐야 하고, 테스트가 같은지 확인합니다.
- 새 mod 폴더를 만들 때는 `mod.json` 을 먼저 만드세요(위 [원하는 기능만 설치하기](#원하는-기능만-설치하기)의 이유). `install.ps1` 도 그 순서로 복사합니다.
- `docs/superpowers/` 에 기능별 설계 문서와 구현 계획이 있습니다.
- Windows에서 gpui는 Ctrl 단축키를 `"ctrl-s"` 로 보고합니다(문서의 `"cmd-s"` 가 아님).
